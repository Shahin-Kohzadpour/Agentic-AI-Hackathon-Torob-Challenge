# شروع خرید با انتخاب موقعیت

نسخه: `kavoshgaran-2026-10-23-r6-location`

- پیش از ورود به خرید، کاربر بین موقعیت فعلی با GPS و انتخاب دستی روی نقشه تصمیم می‌گیرد. مجوز موقعیت بدون لمس دکمه درخواست نمی‌شود.
- انتخاب دستی با حرکت نقشه یا لمس نقطه انجام و سپس تأیید می‌شود. انتخاب در نشست ذخیره است و از بخش شرایط خرید یا سربرگ قابل تغییر است.
- رد مجوز، موقعیت خارج تهران و پاسخ دیررس GPS مدیریت می‌شوند. پاسخ دیررس نمی‌تواند انتخاب دستی را عوض کند.
- متن و برچسب‌های فنی از رابط خرید و مسیر `/demo` کنار گذاشته شده‌اند. قیمت ثبت‌شده، موجودی نیازمند تأیید و برنامهٔ مراجعه با وضعیت واقعی اطلاعات سازگار می‌مانند؛ کارت، رزرو یا تأیید قطعی فروشگاه محسوب نمی‌شود.
- برنامهٔ مراجعه از قیمت ثبت‌شده استفاده می‌کند؛ مبلغ حاصل از سناریوهای داخلی به‌عنوان قیمت تازهٔ فروشگاه نمایش داده نمی‌شود. سوابق داخلی منبع اطلاعات حفظ می‌شوند.

اعتبارسنجی: ۵۹ آزمون سرویس، production build و بررسی انواع و lint موفق بودند. دو مجموعهٔ مرورگر روی خروجی production محلی پاس شدند: انتخاب GPS/نقشه و مسیر کامل خرید در چهار عرض موبایل. کاشی‌های واقعی نقشه بارگذاری شدند و خطای JavaScript صفر بود. آزمون GPS از موقعیت و مجوز کنترل‌شدهٔ مرورگر استفاده می‌کند؛ اجرای فیزیکی گوشی را ادعا نمی‌کند.
